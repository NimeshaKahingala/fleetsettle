# FleetSettle

A ledger for a small Sri Lankan vehicle-rental business — a bus and two cars, run by two partners, one of whom does all the data entry and the other of whom reads the reports.

Start with [CLAUDE.md](CLAUDE.md) — repository state, the rules that must not be broken, and where everything else lives. The specification itself is [docs/README.md](docs/README.md), which maps the seven documents that decide what this system does and why. [TRACKER.md](TRACKER.md) is what is built; [Plan.md](Plan.md) is what remains; [DEPLOYMENT.md](DEPLOYMENT.md) is how it ships.
